# Format: <filename> <fail|hang|flaky>   ('#' starts a comment)
#   fail  = builds but exits nonzero (failed Test.assert_* / panic / crash)
#   hang  = never terminates; killed by the runner watchdog

#           reliably green nor reliably red

#   WYN=./wyn bash tests/stdlib/run_stdlib_tests.sh --update-allowlist

# entry by hand afterwards.)
